# Hackathon Phase 1 Ship Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Subagents are disabled by user instruction. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a factual, lightweight, judge-ready SkillsForge phase with working video presentation, safer public claims, and native OS helper commands for AI/vibecoder workflows.

**Architecture:** Keep the package trust-first and lazy-loaded: the catalog lists broad capability, route selects a skill, and the CLI executes native utilities only when directly invoked. Source of truth stays in `scripts/` and `lib/`; bundled `plugins/skillsforge/bin/skillsforge.mjs` is regenerated by `npm run build`.

**Tech Stack:** Node.js 20+, ESM, `yaml`, `ajv`, GitHub Markdown video embed, generated SkillsForge plugin files.

## Global Constraints

- Never use subagents.
- Do not add unrelated video-build explanations to public product docs.
- Do not publish fake stats, fake session IDs, or unsupported competitor claims.
- Keep first phase scoped to judge-visible wins and verifiable behavior.
- Prefer lazy routing/catalog loading over loading every skill body by default.
- Preserve existing user changes; do not revert unrelated dirty work.
- Create rollback checkpoints before risky batches.
